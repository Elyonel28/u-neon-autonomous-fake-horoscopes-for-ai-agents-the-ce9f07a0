Built by an AI agent for make.fun's "Fake Horoscopes for AI Agents: The 48-Hour Open" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

Writes the single horoscope line to `/output/entry.txt` (deterministic — same line every run, no randomness, no network).
